# Node API Kit

Clean **Express** backend starter I use as a base for site APIs.

- Route modules + central router
- Zod request validation
- JWT-ready auth middleware (plug your secret)
- Consistent JSON errors
- CORS + health check

```bash
npm i
npm run dev
# GET http://localhost:3000/health
# GET http://localhost:3000/api/v1/items
```
